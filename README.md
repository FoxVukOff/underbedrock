# Under Bedrock — мод для Horizon (Minecraft 26.3)

Мир **под бедроком**: бедрок больше не дно. Кирка из зачарованного сплава пробивает
бедрок удержанием, а под ним — 512 блоков нового мира: пустотный камень, эфириум,
эфирные кристаллы и ванильные руды в новой породе. Новая руда, новые блоки, свои
текстуры (16×16, нарисованы вручную), русский и английский языки.

Мод состоит из трёх частей, которые ставятся вместе:

| Файл в `release/` | Что это | Куда класть |
| --- | --- | --- |
| `underbedrock.hmod` | контент-мод: блоки, предметы, рецепты, лут, руда, вкладка, языки | `horizon-mods/` |
| `underbedrock_core.hnmod` | нативный мод: ломание бедрока, прогресс, команды `/etherium` | `horizon-native-mods/` |
| `underbedrock_world.zip` (или папка `datapack/underbedrock_world`) | датапак мира: высота −576..319, шум, пустотный камень и его пещеры | `saves/<мир>/datapacks/` |

---

## Что появляется в игре

**Мир под бедроком.** Обычный мир Horizon заканчивается на y = −64. Датапак
`underbedrock_world` заменяет тип измерения и настройки шума Overworld'а: мир
становится высотой 896 блоков, от y = −576 до y = 319. Бедрок по-прежнему лежит
полом на y = −64..−60, но под ним теперь не пустота: слой **пустотного камня**
(`underbedrock:voidstone`) с жилами эфириума и кристаллов, алмазами и железом.

**Эфириум.** Новая руда двух сортов:
- в обычном мире — в deepslate и камне на y = −60..−16, небольшими редкими жилами,
  чтобы кирку можно было сделать **до** похода под бедрок;
- под бедроком — богато: эфириум (y −540..−96), эфирные кристаллы (y −520..−90),
  плюс алмазы и железо в пустотном камне.

Из руды падает **необработанный эфириум**, плавка (или плавильная печь) даёт
**слиток зачарованного сплава**. Рецепты: слиток из руды, кирка из трёх слитков и
двух стержней пламени, блок эфириума и обратно, пустотный кирпич из пустотного
камня.

**Кирка из зачарованного сплава.** Прочность 2800, скорость 14 (быстрее незеритовой),
светится зачарованным блеском. Единственный инструмент, который берёт бедрок:
удерживайте левую кнопку на бедроке — над хотбаром пойдёт полоса прогресса,
по умолчанию бедрок сдаётся за 3 секунды. Креатив ломает бедрок мгновенно, как в
ванили, — механика прогресса работает в выживании и приключении.

**Блоки:** пустотный камень, пустотный кирпич, эфириумовая руда, эфириумовый блок,
эфирный кристалл. Всё в творческой вкладке «Подбедрок».

## Установка

Нужен Horizon версии 26.3. Моды в Horizon **выключены по умолчанию**: свежеустановленная
игра не имеет папки `horizon-mods` и играет как ваниль.

### 1. Контент-мод
Скопируйте `release/underbedrock.hmod` в папку `horizon-mods/` вашей игры (инстанса
лаунчера; папку можно создать самому). Включите мод: **Настройки → Моды → Under Bedrock**,
или строкой `mod.underbedrock:true` в файле `horizon-mods.txt` рядом.

### 2. Нативный мод
Скопируйте `release/underbedrock_core.hnmod` в папку `horizon-native-mods/` и включите
тем же способом. При первом включении лаунчер **соберёт свою сборку игры** с этим модом:
нужен интернет (скачивается Rust-тулчейн и исходники Horizon, один раз, несколько минут).
Мод использует только официальные hook points (`hooks: 126`), поэтому собирается на любой
Horizon, где hook points версии 126 или новее; лаунчер сам выберет ревизию.

> Нативный мод — это код, который выполняется с вашими правами. Horizon спросит
> согласие на сборку; исходники мода лежат прямо внутри `.hnmod` (это zip:
> `mixins/underbedrock_core/*.rs`), их можно прочитать до установки.

### 3. Датапак мира — только для НОВОГО мира
Высота мира задаётся при создании/загрузке мира, поэтому датапак должен быть включён
до того, как мир сгенерирует чанки. Два способа:

**Способ А (проще).** Создайте новый мир, выйдите в меню. Распакуйте
`release/underbedrock_world.zip` (или скопируйте папку `datapack/underbedrock_world`)
в `saves/<имя мира>/datapacks/`. Датапаки-папки (`file/…`) включаются игрой сами —
в `datapacks.json` их можно не прописывать. Зайдите в мир: он высокий.

**Способ Б.** Положите папку `underbedrock_world` в
`<инстанс>/.local/horizon-client/26.3/data/minecraft/datapacks/` — тогда датапак
появится на экране создания мира среди «экспериментов»/датапаков: включите его там
и создайте мир.

Где лежит `saves/`: в папке игры (инстанса), рядом с `horizon-mods/`.

> Чанки, созданные **до** включения датапака, останутся старой высоты: под их бедроком
> будет пустота. Играйте в мире, созданном с датапаком, или уходите подальше от старых
> чанков.

### 4. Проверка
В мире выполните `/etherium depth`. Ответ `This world: y -576 .. 319 (896 blocks).
Under Bedrock's world is below the bedrock floor.` — всё встало. Если мир обычный,
мод один раз напишет в чат строку `NOT tall: install the datapack…` — значит, датапак
не включён для этого мира.

## Как играть

1. Спуститесь в deepslate (y −60..−16) и найдите **эфириумовую руду** — бирюзовые
   прожилки с фиолетовыми искрами. Железная кирка и выше её берут.
2. Выплавите слитки зачарованного сплава, скрафтите кирку: три слитка сверху,
   два стержня пламени под ними.
3. Найдите бедрок (дно мира, y −64) и **удерживайте** на нём левую кнопку с киркой.
   Над хотбаром: `Bedrock [##########----------] 50%`. Отпустите — прогресс сбросится.
4. Бедрок исчезнет, и в инвентарь упадёт блок бедрока (если дроп включён). Ниже —
   пустотный камень и его руды. Света там нет: берите факелы.

### Команды

| Команда | Что делает |
| --- | --- |
| `/etherium` | список команд |
| `/etherium give` | даёт кирку из зачарованного сплава |
| `/etherium depth` | высота мира и стоит ли датапак |
| `/etherium dig` | следующее время ломания бедрока (1 / 2 / 3 / 5 / 10 с) |
| `/etherium drop` | падает ли бедрок предметом |

### Настройки мода
**Настройки → Моды → Under Bedrock**: две кнопки — время ломания бедрока
(1 / 2 / 3 / 5 / 10 секунд) и дроп бедрока (ON / OFF). Хранятся в
`horizon-mods/.horizon-mod-data/underbedrock_core/`.

## Известные ограничения

- Ломание бедрока — механика выживания/приключения; в креативе бедрок ломается
  мгновенно средствами самой игры.
- Во время удержания слышен обычный звук копания (его шлёт движок); отдельного звука
  и частиц в момент слома нет — у Horizon нет hook point'а на них.
- Прочность кирки за сломанный бедрок не тратится (нет hook point'а на урон предмета);
  за обычную добычу тратится как у любого инструмента.
- Мир должен быть создан с датапаком (см. установку).
- Нативный мод читает одно приватное поле движка (`Game::mining` — состояние копания
  игрока), чтобы точно знать, держит ли игрок кнопку. Если в будущей версии Horizon
  поле переименуют, сборка мода упакёт понятной ошибкой компиляции, а не тихим багом.

## Сборка у себя (Windows и любые ОС)

Готовые файлы можно не искать: мод собирается из этого репозитория одним Питоном,
Раст не нужен совсем (он нужен только проверкам).

1. Поставьте Python 3.11 или новее (с python.org; при установке отметьте
   «Add Python to PATH»). Больше ничего не требуется.
2. В PowerShell или терминале:

   ```
   git clone <адрес этого репозитория>
   cd underbedrock
   python tools/pack_release.py
   ```

   (если `python` не находится — `py tools/pack_release.py`)
3. В папке `release/` появятся те же четыре файла: `underbedrock.hmod`,
   `underbedrock_core.hnmod`, `underbedrock_world.zip` и пачка
   `underbedrock-install.zip` с `INSTALL.txt`. Дальше — установка по шагам выше.

Проверки (по желанию, нужен Rust 1.85+):

```
cd native-mod && cargo test                      # логика нативного мода
cd ../tools/stubcheck && cargo run -- on && cargo run -- off   # исходники мода против сигнатур Horizon, 34 сценария x2
cd ../.. && python tools/nativecheck.py release/underbedrock_core.hnmod
```

Полный цикл (текстуры и контент генерируются заново, контент-мод пакуется парсером
самой Horizon, все проверки) — `sh tools/build_all.sh`; на Windows это Git Bash,
и в первый раз он скачает зависимости Раста.

## Исходники и пересборка

```
content-mod/            контент-мод (блоки, предметы, рецепты, лут, язык, текстуры)
datapack/underbedrock_world/
                        датапак: dimension_type, noise_settings, density-функции,
                        правила материалов, руды (configured/placed features,
                        biome modifiers для обычного мира)
native-mod/             нативный мод: mixins/underbedrock_core/ — runtime.rs (логика
                        и тесты) и по одному helper-файлу на hook point
tools/make_textures.py  рисует все текстуры (Pillow)
tools/make_content.py   генерирует content-mod/ и datapack/ из одного места
tools/modbuild/         пакует и проверяет контент-мод парсером самого Horizon
tools/nativecheck.py    читает .hnmod теми же правилами, что реестр Horizon
tools/stubcheck/        компилирует исходники нативного мода против точных сигнатур
                        Horizon и прогоняет 34 сценария в двух конфигурациях
tools/pack_release.py   собирает release/ одним Питоном, без Раста (ваш вариант на Windows)
tools/build_all.sh      всё вышеперечисленное одним запуском (Раст + Horizon-парсер)
```

Пересборка (Rust 1.95, python3 с Pillow): `sh tools/build_all.sh`. Прогон проверок
по отдельности: `cd native-mod && cargo test`, `cd tools/stubcheck && cargo run -- on`
и `-- off`, `python3 tools/nativecheck.py release/underbedrock_core.hnmod`.

Версии, на которых мод сделан и проверен: Horizon `ea55997` (26.3, hook points v126,
NATIVE_HOOKS_API 153), horizon-mixins `ddd9700`. Форматы `.hmod`, `.hnmod`, датапака
и всех JSON сверены с исходниками Horizon этой ревизии.
